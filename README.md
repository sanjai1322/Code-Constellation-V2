# Code Constellation website

Light-theme studio site for Code Constellation — *From idea to orbit.* Built in Tamil Nadu, India; working worldwide.

The deployable site is the buildless static folder `dist/` (HTML, CSS, JS, local assets). The interaction patterns follow https://two26.studio/ (see `docs/REFERENCE-CHECKLIST.md`), with our own brand, content and artwork.

## Run

```bash
python tools/serve.py
```

Then open http://127.0.0.1:8765/.

Unknown paths return the custom page with HTTP 404 locally. Preview it directly at `/404.html`.
The 404 page uses the approved coder, designer and 3D companion together in
`assets/404/trio-loop.webm` (1280×720, 24 fps, alpha, muted). The selected Flow
clip is `Animate_character_illustration_loop_6c08d129_gwr_video_mvp.mp4`.
Its green screen is keyed and despilled; an eight-frame circular dissolve joins
the tail to the head, making a 184-frame / 7.667-second forward loop.
`trio-loop.webp` supplies Safari's animated fallback, while `trio-searching.webp`
matches the first frame for loading and reduced motion. CSS drift stops when
the real animation is active. Pause, tab visibility and offscreen controls stop
playback; reduced motion keeps the still. Regenerate HTML after changing assets
with `node tools/build-pages.mjs`.

## Services journey

The winding line is generated at runtime from the real positions of the illustrations (the services-journey `build()` in `js/home.js`). Segments are cubic curves whose handles never point upward, so the line is monotonic in Y: a fixed viewport line (62% of the height) maps to exactly one point, which is where the stroke ends and the marker sits. Geometry is rebuilt on ScrollTrigger refresh, after fonts load and on any size change of the journey. On mobile the illustration sits on the line's side and the text column on the other, and the line exits each illustration sideways into the free channel.

Clips play only while visible and the tab is visible; the "Pause animations" button pauses them; reduced motion shows posters only. Safari (no VP9 alpha) gets animated WebP that swaps back to the poster when paused.

## Selected work carousel (liquid-glass lens)

`js/liquid-carousel.js` (ES module, loaded on demand by `home.js`) renders the carousel with **Three.js r169** (MIT, vendored at `assets/vendor/three/`):

1. The six project panels are drawn into an off-screen `WebGLRenderTarget` (4× MSAA).
2. A full-screen shader refracts that target through an animated glass lens: a rotated ellipse with a wavy rim, chromatic dispersion toward the edge, an inner glow, a coloured rim ring, a halo and a moving shimmer band.
3. Motion: target/current scroll with a glide factor, drag inertia, delayed snapping, speed-based shrink, panels that bow against their motion, image glide inside each frame, a GSAP entry (small scattered images rise, grow into the strip, then the glass develops) and a focus state (the selected project scales up, neighbours dim, the glass eases back).

The starting values are the reference component's settings, kept in `SETTINGS` at the top of the module: `panelHeight 450, gap 12, glide 0.075, wheelSensitivity 1, snap true, snapDistance 60, snapDelay 120, speedShrink 60, lensShape "circle", lensRotation 65, lensWidth 0.565, lensHeight 1, lensX 0.5, lensY 0.5, dispersion 11, zoom 0, blur 0, glow 4.2, blueRing 6, blueColor "#009dff", shimmer true, rimWave 0.6, entryAnimation true, focusScale 1.18, pixelRatio 2`, with the background set to Starlight `#F1F2FB`.

- Titles, type labels, the counter and the "View project" link are HTML outside the canvas.
- Horizontal drag, horizontal trackpad swipe, previous/next buttons, ←/→/Home/End, Enter to select and Escape to close. Vertical wheel and vertical touch scrolling always scroll the page (`touch-action: pan-y`).
- Three.js downloads only when the section is near; rendering runs only while the stage is visible and the tab is visible (and only while moving when "Pause motion" is on); device pixel ratio is capped at 2; textures, materials, geometry, the render target and the context are released on `pagehide` and rebuilt on back/forward restore.
- Reduced motion, no WebGL2, software-only rendering or a lost context fall back to the static project card list.
- `?glass-test` enables software WebGL and a test hook for automated checks.

**About the reference.** The lens shader and its optical defaults are adapted from Liquid Carousel by [@luxarma](https://luxarma.fr), module version kpCFFax8ciLkuLf0kMrs: https://framer.com/m/liquid-glass-carousel-SkrkTr.js@kpCFFax8ciLkuLf0kMrs. Its height-normalized lens axes, angular tangential distortion, 16-sample chromatic dispersion, rim highlights and shimmer are preserved. The site integration provides navigation, visibility/paused rendering, resource cleanup and accessible fallbacks. Panel sizing follows the reference's container-height and mobile-width limits.

## Work page and card hover

`work.html` lists every project with type filters (All / Client work / Concept / Unofficial concept / Lab). Cards share one hover, adapted from the reference recording: a blob in the project's palette colour grows from the corner the pointer entered, then a detail crop of the cover follows it; leaving reverses it. Colours and crop focus points are set per project in `CARD_STYLE` in `tools/build-pages.mjs`. Touch and reduced motion get a simple, static card.

## Team portraits (About page)

The "Meet the team" cards show a lavender placeholder with an initials badge until a portrait exists. To add one:

1. Save a 4:5 portrait (at least 1000 × 1250) as `dist/assets/team/sanjai.webp`, `subhiksha.webp` or `sandeep.webp`, or set `photo` for that person in `TEAM` in `tools/build-pages.mjs`.
2. Run `node tools/build-pages.mjs`.

The card keeps its 4:5 frame (`object-fit: cover`). Only names and roles are shown; there are no biographies, links or credentials. The hover treatment (slight lift, portrait tilt toward the pointer, soft light, cobalt hairline) is an interpretation: the Framer "Showcase Card" component referenced in the brief could not be opened from the build environment, so it was not inspected or reused.

## Sound

`js/sound.js` synthesizes every sound with the Web Audio API — no audio files. Off by default; once turned on it stays on for the session across pages and resumes on the next tap or key. One palette (D major pentatonic, soft sine/FM bells, a shared reverb and a limiter): hover ticks (mouse only), tap plucks, a whoosh on page transitions, a glass note per carousel project, an arpeggio of rising notes as the services line reaches each star, a card flick, FAQ open/close, dialog, copy and filter sounds, the mascot's "Hi!" chirp, and an ambient pad with occasional twinkles. On iOS it uses the "ambient" audio session (respects the silent switch, mixes with the visitor's music). Add `?sfx-debug` to log sound errors.

## Motion control

Everything animates by default. One "Pause motion" button in the corner dock (every page) stops looping motion everywhere — hero clip, marquee, ribbon, orbit star, service clips, carousel shimmer, About gallery — and is remembered for the session. It is kept because WCAG 2.2.2 requires a way to stop motion that loops for more than five seconds. Reduced-motion users get static versions.

### Character prompt (for new poses)

Attach the approved character sheet every time and generate one PNG per pose:

> Preserve the exact approved character's face, silhouette, proportions, costume, materials and colors. Change only the requested pose: [POSE]. For the mascot preserve the smooth 3D cobalt body, single curled cyan/lavender crest, ivory face, star-highlighted navy eyes, lavender cheeks and feet, and orbital C chest emblem. For humans preserve the original hand-drawn style and exact outfits. One full-body character, all limbs within frame, clean transparent alpha background, no ground shadow, no haze, no labels or decorative borders. Never substitute the rejected hand-drawn blue companion.

## Brand book

Layout and copy follow the Code Constellation Brand Book v1.0 (October 2026): Geist 400/500 with tight headline tracking; Geist Mono eyebrows, uppercase, tracked 14%; sentence case everywhere else; left-aligned by default with only single lines centred; graphic devices used: orbit lines, the star dot, constellation links, orbit path, a 4px dot grid (image slots) and mono technical annotations; one glow per frame. About-page mission, vision, values, client journey and pillars are quoted from the book.

## Image placeholder slots (case studies)

Each case page has a "Selected frames" gallery of reserved slots (16:9, 4:5, 4:3, 21:9 and three 1:1). To add an approved image, edit `tools/build-pages.mjs` (or the generated page) and replace the slot's `.slot-frame` element with `<img src="…" alt="…">`; the slot keeps its aspect ratio and corner radius.
